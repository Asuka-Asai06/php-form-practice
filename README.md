# php-form-practice

## 概要
COACHTECH 教材 Tutorial 7-4「フォームとデータ受け渡し ハンズオン演習」で作成した成果物です。
基本的なユーザー登録フォームを作成しました。

## 使用技術
- PHP 8.5.4
- HTML5（フォーム要素）

## 学んだこと
- HTMLフォームからPHPに値を渡し、受け取る仕組み
- 隠しフィールドを使ってデータを渡す仕組み
- htmlspecialchars によるXSS対策の必要性と、実際の使用方法
